# Shared style + citation keys (binding for all section drafts)

## Register
- Academic, deflationary measurement science. Present tense for the framework
  ("we introduce", "we define"), future-neutral for the pilot ("the pilot
  will run / is designed to"). NEVER report empirical results — none exist.
- Hypotheses/contrasts use "may", never "do".
- Banned terms (except when explicitly disclaiming them): panic, frustration,
  emotional instability, suffering, meltdown, emergent mind, subjective stress.
- "Pressure" is an externally imposed task-environment property;
  "destabilization" is trace-observable behavior. Restate this where natural.
- Markdown prose, `##`-level section heading, `###` subsections. Tables and
  fenced code blocks where the plan/spec uses them.
- Implementation substrate referred to generically as "a trace instrumentation
  framework"; Maida is named at most once in the whole paper (Discussion owns
  that mention if used at all).
